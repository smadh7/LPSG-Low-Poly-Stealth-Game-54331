HITMAN — CORAL PALM RESORT
==========================

An original, offline, third-person stealth game set on a tropical island
resort. No installer, no account, no internet connection required.

------------------------------------------------------------------
STARTING THE GAME
------------------------------------------------------------------
Double-click "HITMAN Coral Palm Resort.exe".

That is the whole installation. The folder can be moved or copied anywhere you
have write access — a USB stick, your Desktop, a games folder — and it will
still run. Do not put it inside C:\Program Files: Windows protects that
directory, and the game stores its settings next to your user profile, not
there, but keeping the game somewhere writable avoids any surprises.

To remove the game, delete the folder.

------------------------------------------------------------------
SYSTEM REQUIREMENTS
------------------------------------------------------------------
Minimum
  OS      Windows 10 or Windows 11 (64-bit)
  CPU     Dual-core 2.4 GHz
  RAM     8 GB  (16 GB recommended)
  GPU     Intel Iris Xe / any DirectX 12 capable integrated GPU
  Disk    ~250 MB free
  Display 1280x720 or larger

The game is tuned to hold a steady frame rate on Intel Iris Xe graphics at
1080p using the Medium graphics preset. If frames are low, open
Settings -> Graphics and choose Low.

------------------------------------------------------------------
CONTROLS
------------------------------------------------------------------
  W A S D         Move
  Mouse           Look around
  Shift           Run
  Ctrl            Crouch / sneak
  Space           Jump
  E               Interact (doors, objects, people)
  Tab             Inventory
  F1              Objectives / mission briefing
  Esc             Pause menu (settings, save, load, quit)

Controllers are not supported in this build.

------------------------------------------------------------------
SAVED SETTINGS
------------------------------------------------------------------
Graphics, audio and gameplay settings, plus save games, are written to your
Windows user profile:

  %APPDATA%\CoralPalmResort\

Nothing is written to the game folder or to any protected directory, so the
game works for a standard (non-administrator) Windows user.
